# WonderHug Flutter app

Native companion (not a WebView). Bottom navigation: Home, Journey, Learn, Community, Profile.

## Run

```bash
flutter pub get
flutter run --dart-define=SUPABASE_URL= --dart-define=SUPABASE_ANON_KEY=
```

Platform folders (`android/`, `ios/`) are created with `flutter create .` inside this directory when the Flutter SDK is available.

## Tests

```bash
flutter test
```
